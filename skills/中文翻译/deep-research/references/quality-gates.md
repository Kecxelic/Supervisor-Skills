# 六道内部质量门禁

仅内部使用；永不展示给读者。每道门禁有检测问题、三级判定（CLEAR / SUSPECTED / INSUFFICIENT）和失败路由。

## 视角（CRITICAL）

**失败模式**：输出是主题罗列，不是有判断的综述。

检测：
1. 综述的核心判断能否用一句话陈述？仅命名主题意味着视角从未确立。
2. 与原始搜索结果列表相比，这篇增加了什么判断？如果答案是"更好的格式"，它不是综述。
3. 视角与同领域已有综述有何不同？

寻找强视角：最好的视角来自独立来源间意外的趋同或张力：多个不相关的 benchmark 指向同一结论；理论担心的与实践挣扎的之间存在系统差距；不同学科通过不同路线到达同一瓶颈。如果每篇论文说的差不多一样，视角就是"共识已形成，但在条件 X 下仍有争议"。

**路由**：回到纲要；重新推导视角。

## 覆盖（MAJOR）

**失败模式**：关键工作缺失；结论建立在部分证据上。

检测：
1. 每个子方向有三篇以上工作？
2. 每个分类法单元有文献吗，每个空单元是真正的空白而非搜索遗漏？
3. 已找到的论文本身高频引用的工作是否在列表中？
4. 是否有方法流派或研究组完全缺席？
5. 被丢弃的搜索结果是否指向未覆盖的子方向？

**路由**：针对性补充搜索（回到侦察阶段）。

## 引用（CRITICAL）

**失败模式**：引用不存在或被误引。

检测：
1. 每条引用是否通过了验证协议？
2. 正文中引用的每个具体发现是否可从论文标题或摘要确认？
3. 是否有标题与所论证观点惊人完美匹配？
4. 被引用三次以上的作者：每条是否独立验证？

**路由**：回到验证；编造引用发现即删除，连同依赖它的每个判断。

## 分类（MAJOR）

**失败模式**：论文逐篇列出而非按主题组织。

检测：
1. 节标题是主题名还是论文名？
2. 轴是否互斥且穷尽？
3. 空单元是真正的空白还是轴选择的产物？
4. 跨类论文是否被识别并讨论？

**路由**：重新设计轴或重新分组。

## 分寸（MAJOR）

**失败模式**：判断强度与证据强度不成比例。

检测：
1. 每个"demonstrates / establishes"是否基于多项独立研究？单项研究只能用"suggests"。
2. 有无限定的最高级（"X is the best approach"）？
3. 反向失败：强趋同证据被对冲成模糊（"may possibly suggest"）？

**路由**：按对冲阶梯重新校准措辞。

## 交织（MAJOR）

**失败模式**：论文孤立摘要；无句内比较。

检测：
1. 每个主题段是否至少有一句引用并比较两个以上工作？
2. 有无"A did X. B did Y. C did Z."的串行罗列？
3. 矛盾是否以条件分析呈现，还是被"this is debated"带过？
4. 比较表是否揭示有意义差异（列为维度，标题陈述结论）？

**路由**：按综合框架重写标记段落。
