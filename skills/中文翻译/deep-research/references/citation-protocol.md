# 引用验证协议

## 两步验证

对每条候选引用：

**步骤 1：存在性。** 搜索完整标题（或一个独特片段加第一作者姓氏）。
- 找到且标题和作者匹配：存在性通过。
- 找到但标题或作者不同：标记并确认是否为同一工作。
- 未找到：评级为不可验证；不进入综述。绝不保留并附警告标签。

**步骤 2：引用准确性。** 正文中引用的发现是否与论文标题和摘要匹配？仅有元数据时，不编造方法细节或具体数字。

## 五级判定

| 等级 | 含义 | 可用 |
|---|---|---|
| 已验证 | 存在；引用匹配 | 是 |
| 轻微 | 存在；措辞有小漂移 | 是，修正后 |
| 重大 | 存在；引用歪曲了原文 | 否，修正或删除 |
| 不可验证 | 存在性无法确认 | 否 |
| 付费墙 | 存在；元数据不足以支撑声称 | 仅限元数据级陈述 |

## 灰区即不使用

不可确认的引用不进入。"大概有一篇论文展示了 X"但无检索命中：不引用。少一条引用永远好过多一条编造引用。

报告正文中，不可用来源留下的空白使用统一未确认标记，例如"[未确认：该方向未检索到工作]"。这是研究报告约定，不是论文约定：综述报告是给研究者看的工作材料，显式未确认标记是诚实信号。论文正文（paper-writer 和 intro-drafter 技能）禁止所有此类标记；两种制度是不同产品，差异是刻意的。

## 对编造引用零容忍

检测信号：

- 标题与所论证观点惊人完美匹配；
- 作者-标题-年份-会议组合检索零命中；
- 一位作者在列表中出现多次但检索中仅出现一次。

发现编造引用时：立即删除，然后重新审查依赖它的每个判断。
