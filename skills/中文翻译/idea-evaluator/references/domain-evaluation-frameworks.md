# 非 STEM 研究想法的评估框架

## 目录

1. 人文与社会科学：五维度
2. 人文与社会科学：致命缺陷替换
3. 金融与经济学：五维度
4. 金融与经济学：致命缺陷替换
5. 选择框架

当想法不是 STEM 或技术类（核心无实验、benchmark、模型或算法）时，更高/更快/更强/更省/更广框架不适用。使用下方替代维度。按**研究方法**分类，绝不按院系名：传播学做话语分析按人文学科评估；传播学做问卷调查按经验社会科学评估。

## 1. 人文与社会科学：五维度

覆盖文学、历史、哲学、政治、社会学、教育、传播、艺术及相邻领域。

**1. 理论贡献。** 想法在理论层面推进了什么：新解释框架、对已有框架的非平凡扩展或修正、或在新材料上对旧假设的新测试。
打分：9-10，可能改变方向讨论方式的全新概念工具；6-8，非平凡扩展、修正或跨领域移植；3-5，将已有理论应用于新材料但理论本身无推进；1-2，无理论视角，纯描述。

**2. 方法创新。** 设计是否以不同方式看材料：新文本分析策略、新档案组合、新跨领域视角、新田野方法？
打分：9-10，产出此前不可能发现的方法设计；6-8，深思熟虑的方法选择匹配问题；3-5，常规方法，无设计思考；1-2，方法与问题不匹配。

**3. 经验发现。** 揭示了什么此前未记录、未系统化或未解释的现象？一手文献、被遮蔽的历史事实、定性材料中的新模式都算。
打分：9-10，有潜力转变领域理解的重要被忽视现象；6-8，系统化已知但记录不足的模式；3-5，确认已有发现无新信息；1-2，无经验发现，纯推导。

**4. 解释力。** 能否用更少假设解释更多现象：更好的一致性、更少例外、比现有叙述更锐利的边界条件？
打分：9-10，统一此前竞争的解释；6-8，覆盖最佳现有叙述遗漏的重要反例或边界条件；3-5，与已有叙述相当；1-2，比已有叙述更窄。

**5. 社会意义。** 对政策、实践、公共话语或特定社区有可操作的启示？非强制，但有的话是加分。
打分：9-10，直接对话活跃政策或公共辩论且可能转变决策框架；6-8，对实践领域有间接但可识别的启示；3-5，主要是理论意义；1-2，学术界内部。

打分纪律与 STEM 版一致：从 5 起步，仅有依据才上移（材料证据或机制论证）。人文的机制论证不是消融；而是"此框架解释了反例 X，而竞争框架不能"。

## 2. 人文与社会科学：致命缺陷替换

以下替换 STEM 对应项：

1. **文献参与不足**（替换"与最近工作无新颖性差异"）。领域的核心文本、奠基研究或近期中心辩论未被认真参与，使审稿人怀疑作者是否知道这个对话。
2. **研究问题无法操作化**（替换"不可验证的声称"）。问题太大（"全球化如何塑造文化"）或太模糊，无法设计任何研究回答。
3. **证据不匹配声称**（替换"基线不是真正的基线"）。材料（文本、案例、访谈、问卷）无法承载核心声称；三个案例声称是普遍模式。
4. **方法-范式冲突**（新增）。用经验方法回答思辨问题（回归回答"什么是美"），或用思辨方法回答经验问题（用理论代替田野解释社区行为）。
5. **概念漂移**（新增）。核心概念从未锚定且在各节间变换含义。核心概念是人文学科论文的基础；不稳定的基础会沉掉上面的一切。

通用缺陷仍然有效：无令人信服的动机、范围蔓延、从不讨论失败、数据或伦理获取、能力不匹配。

## 3. 金融与经济学：五维度

**1. 识别质量。** 因果识别有多可信：什么排除了反向因果、遗漏变量、选择偏差？
打分：9-10，有难以挑战的外生性论证的自然或准实验（政策断点、地理边界、意外事件）；6-8，IV 或 DID 有合理但有界的外生性论证；3-5，无识别讨论的控制回归；1-2，相关呈现为因果。

**2. 经济量级。** 统计显著不等于经济显著：效应大到对政策或决策有意义吗？
打分：9-10，大到能推动政策辩论或投资决策；6-8，经济上不可忽略；3-5，存在但小；1-2，仅统计显著，经济含义不清。

**3. 机制新颖性。** 是否揭示了新传导渠道，而非仅新相关：A 为什么移动 B，通过什么？
打分：9-10，此前未记录的渠道，通过中介分析或结构模型分解；6-8，通过已知渠道解释新现象；3-5，记录相关但无机制讨论；1-2，黑箱回归。

**4. 数据贡献。** 新数据集或已有数据中的新风格化事实：手工收集的微观数据、行政数据集的首次学术使用、新跨国面板。
打分：9-10，成为领域基础设施的数据集；6-8，首次使用行政或调查来源回答此问题；3-5，公开数据集；1-2，过度挖掘的经典数据无新内容。

**5. 政策相关性。** 能告诉政策制定者"做 X 产生 Y"吗？
打分：9-10，直接回答有争议的政策问题且识别足够强；6-8，间接但可识别的政策含义；3-5，主要是学术的；1-2，与政策无关。

学科注意：在此领域，识别可信度高于效应量。小而干净的识别效应胜过大而内生的效应。

## 4. 金融与经济学：致命缺陷替换

1. **内生性未处理**（替换"不可验证的声称"）。无可信策略应对反向因果或遗漏变量的因果声称。
2. **样本选择偏差**（替换"基线不是真正的基线"）。抽样使泛化不可能：上市公司代表"企业"，一家银行的客户代表"消费者"。
3. **p-hacking 信号**（新增）。仅报告显著结果；尝试多种规范，展示最漂亮的；无稳健性检验。
4. **缺失稳健性**（新增）。核心结果从未用替代度量、时期或规范重跑。审稿人期望至少两三个稳健性检验。
5. **经典文献缺失**（替换"与最近工作无新颖性差异"）。方向的奠基论文或近期综述既未引用也未讨论。

## 5. 选择框架

在第一印象步骤中按方法信号决定：

| 信号 | 范式 | 框架 |
|---|---|---|
| 实验、benchmark、消融、模型架构 | STEM / 技术 | 原始五维度（更高/更快/更强/更省/更广） |
| 文本分析、档案、概念论证、话语分析 | 人文学科 | 人文学科五维度 |
| 问卷、访谈、统计、案例研究、田野调查 | 经验社会科学 | 人文学科五维度，侧重经验发现和方法创新 |
| 回归、IV、DID、RDD、面板数据、金融变量 | 金融 / 经济学 | 金融五维度 |
| 法律、案号、判例、教义比较 | 法学 | 人文学科五维度，侧重理论贡献和社会意义 |
| 不清楚 | 问一个问题 | "核心方法是实验、问卷、文本分析还是理论推导？" |

跨范式想法（"用 NLP 方法研究政治话语"）按**核心贡献**分类：如贡献是 NLP 方法，STEM；如是政治学发现，人文学科。
