设计系统、可复现、可扩展的数据构建管线。管线是 Benchmark 论文的核心技术贡献，相当于技术论文的"方法"章节。

## 管线设计原则

每个构建管线必须满足三个性质：

1. **可复现性**，另一团队按相同步骤可获得可比数据
2. **可扩展性**，管线可生成更多数据而不按比例增加人力
3. **质量保证**，每个数据点通过显式质量门

## 三种已验证的构建范式

选择最适合你任务的范式，或组合多种范式的元素。

### 范式 1：逆向合成

**StatQA 方法**，先固定答案，再生成问题。

```
定义答案空间 -> 生成匹配条件 -> 组合问题 -> 验证唯一性
   (枚举)          (场景)            (自然语言包装)    (唯一正确答案)
```

**何时使用**：答案空间可枚举（如统计方法、图表类型、代码模式）。需要精确控制难度分布和类别平衡。

**关键优势**：构造上保证无歧义的 ground truth。

### 范式 2：受控注入

**nvBench 2.0 方法**，从干净种子开始，系统注入目标现象。

```
收集干净种子 -> 定义注入类型 -> 在校准级别注入 -> 验证自然度
  (无歧义)        (如 4 种)       (如 5 个严重度)    (人工检查)
```

**何时使用**：研究特定现象（歧义、噪声、偏差、对抗扰动），需要跨现象的受控严重度梯度。

**关键优势**：隔离感兴趣的变量；支持严重度分层分析。

### 范式 3：自适应生成 + 专家标注

**VisJudge-Bench 方法**，用 LLM 生成候选数据，再应用多阶段人工标注。

```
LLM 生成候选 -> 阶段一筛选 -> 阶段二细粒度评分 -> 阶段三交叉验证
  (适配内容)     (专家过滤)     (多维度)            (分歧解决)
```

**何时使用**：任务需要细致的人类判断，无法完全自动化。质量取决于跨多个主观维度的专家评估。

**关键优势**：结合 LLM 的可扩展性和人类的判断质量。

询问用户："哪种构建范式适合这个项目？描述数据来源和粗略管线。"

## 管线阶段规范

<极其重要>
构建管线是审稿人最仔细审查的部分。每步必须有明确的输入、输出和关键操作的详细描述。模糊的管线描述是首要拒稿原因。
</极其重要>

无论采用哪种范式，用此模板记录每个阶段：

| 阶段 | 输入 | 操作 | 输出 | 质量门 |
|------|------|------|------|--------|
| **1. 源选择** | 原始数据源 | 过滤、许可、去重 | 干净来源语料 | 覆盖审计、许可检查 |
| **2. 种子生成** | 来源语料 | [范式特定方法] | 初始样本 | 格式验证、唯一性 |
| **3. 丰富** | 初始样本 | 添加元数据、标签、标记 | 标注样本 | 分类法覆盖平衡 |
| **4. 质量控制** | 标注样本 | 人工审查/自动验证 | 已验证样本 | IAA ≥ 阈值 |
| **5. 划分** | 已验证样本 | 分层训练/验证/测试划分 | 最终数据集 | 分布平衡检查 |

对每个阶段，明确：
- **谁执行**（自动脚本 / LLM / 人工标注者 / 领域专家）
- **耗时多少**（每样本和总量）
- **可能出错什么**以及如何处理失败

## 质量控制策略

记录至少三种策略。审稿人会仔细审查：

| 策略 | 方法 | 何时使用 |
|------|------|----------|
| **标注者间一致性** | 多标注者标注相同样本；报告 Cohen's κ、Fleiss' κ 或 ICC | 任何人工标注任务 |
| **专家抽查** | 领域专家审查随机 ≥10% 子集 | 半自动管线 |
| **对抗验证** | 测试分类器能否区分合成与真实数据 | 合成数据生成 |
| **自动合理性检查** | 基于规则的验证：格式、范围、一致性、去重 | 所有管线 |
| **试点研究** | 全量构建前小规模试运行（50-100 样本） | 复杂多阶段管线 |
| **LLM 交叉验证** | 使用不同 LLM 家族验证 LLM 生成的数据 | LLM 在环管线 |

## 统计特征（第 2.3 节内容）

构建完成后，呈现全面统计：

**必须有（通常 Table 2 + Figure 3-4）：**
- 各划分总样本数（训练/验证/测试）
- 分类法类别分布（柱状图或饼图）
- 难度分布（直方图）
- 文本长度/复杂度分布
- 与已有 Benchmark 的规模比较

**推荐：**
- 词云或主题分布
- 来源多样性指标
- 2-3 个代表性数据示例作为图
- 标注时间和成本统计

## 管线图（Figure 2）

管线必须可视化。设计指南：

- **从左到右或从上到下**流程，方向清晰
- **每步**：标注框，含简要描述
- **步骤间**：箭头标注数据计数（如"10K -> 过滤 -> 8.5K"）
- **质量门**：视觉上区分（菱形、彩色边框或门图标）
- **具体示例**：展示一个样本流经整个管线
- **范式标签**：标明使用哪种构建范式
