# Benchmark 空白分析

系统化识别和阐述评估空白，每篇 Benchmark 论文必须回答的基础问题：**"什么关键能力没有被评估，为什么这很重要？"**

## 步骤 1：调研评估现状

帮助用户绘制已有什么。构建对比表（这成为论文中的 **Table 1**）：

| 维度 | Benchmark A | Benchmark B | Benchmark C | ... | 空白 |
|------|------------|------------|------------|-----|------|
| 任务范围 | | | | | |
| 数据规模 | | | | | |
| 评估维度 | | | | | |
| 粒度级别 | | | | | |
| 真实世界对齐 | | | | | |
| [关键差异点] | ✗ | ✗ | ✗ | | **我们** |

引导用户思考：
- 这个领域已有哪些主流 Benchmark，各自评估什么？
- 它们共享什么隐含假设，该假设在真实场景中是否成立？
- 如果一个模型在每个已有 Benchmark 上都满分，它是否真正掌握了底层能力？

## 步骤 2：识别盲区

空白必须是已有评估的**结构性局限**，不是"需要更多数据"或"需要更大数据集"。三种已验证的空白模式：

### 模式 A：维度盲区
已有 Benchmark 测量能力 X 但完全忽略相关能力 Y。

> **StatQA 示例**：数学推理 Benchmark 测试模型能否算出正确答案，但完全忽略模型能否选择适当的统计方法。一个用错检验但计算正确的模型会得满分，但其推理根本有缺陷。

### 模式 B：假设违反
已有 Benchmark 共享一个隐含假设，该假设在真实场景中不成立。

> **nvBench 2.0 示例**：所有 Text-to-Visualization Benchmark 假设每个自然语言查询恰好映射一个正确可视化。实际上，真实查询天然有歧义，"展示销售趋势"可以合理地产出折线图、柱状图或面积图。当前 Benchmark 惩罚合理的替代解释。

### 模式 C：评估粒度不匹配
已有评估太粗，无法诊断特定失败模式。

> **VisJudge-Bench 示例**：已有可视化评估要么检查表面美学，要么孤立检查信息准确性。但真正的质量需要保真度、表达力和美学的交互。一张图可以漂亮但有误导性，或准确但无法理解。

**询问用户：**
- 观察到的盲区最像哪种模式？（维度盲区、假设违反或粒度不匹配）
- 能否引用一个具体失败案例，已有评估在那里遗漏了真正的问题？

## 步骤 3：验证空白

空白只有通过全部四项检查才值得写论文：

- [ ] **实际影响**：真实用户或应用遇到此问题
- [ ] **可测量**：空白可用具体指标量化，不仅是定性描述
- [ ] **非平凡**：已有 Benchmark 不能简单扩展覆盖（加几个样本不够）
- [ ] **可操作**：识别此空白为模型改进开辟具体研究方向

任何检查失败，空白需要打磨。帮助用户迭代。

## 步骤 4：撰写空白陈述

用以下结构起草 2-3 句空白陈述：

> **[TASK] 的已有 Benchmark 关注 [它们测量什么]，在 [隐含假设] 的假设下运作。然而在真实场景中，[为什么假设失败]。这造成了一个关键的评估盲区：[无法评估的具体能力]，意味着 [后果，看起来表现良好的模型可能出什么问题]。**

空白陈述必须：
- **具体**，命名确切的盲区，不是模糊的"局限"
- **令人惊讶**，挑战社区视为理所当然的常见假设
- **有后果**，展示盲区的真实危害（不只是理论上的不完整）

## 步骤 5：推导研究问题

将空白直接映射到 2-3 个研究问题。RQ 应覆盖三个方面：

| 覆盖领域 | RQ 模板 | 目的 |
|----------|---------|------|
| **Benchmark 构建** | 如何设计一个 Benchmark 来系统评估[盲区]？ | 论证设计选择 |
| **模型能力边界** | 当前模型在[盲区]上失败到什么程度，什么子能力区分强模型 vs 弱模型？ | 确立严重性 + 启用诊断 |
| **人机差距** | 模型与人类专家在[此维度]上如何比较，什么因素（规模/提示/领域知识）影响差距？ | 基准 + 可操作洞察 |

典型 RQ 示例：

| RQ | 模板 | 映射到 |
|----|------|--------|
| RQ1 | 当前模型在[盲区]上失败到什么程度？ | §4.2 总体性能 |
| RQ2 | 什么具体子能力在[此维度]上区分强模型 vs 弱模型？ | §4.3 细粒度分析 |
| RQ3 | [因素：模型规模/提示/领域知识]如何影响性能，模型与人类专家如何比较？ | §4.3 + 人类 vs 模型 |

这些 RQ 将驱动实验设计并结构化论文。每个 RQ 应对应实验章节的一个子节。
