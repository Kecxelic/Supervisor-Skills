## 1. 图表类型决策矩阵

| 图表类型 | 何时使用 | 设计备注 |
|---|---|---|
| 分组柱状图 | 多方法在多 benchmark 上的比较 | Ours 用大胆深色；基线用中性灰；柱顶标值 |
| 折线图 | 参数敏感性、训练曲线、随时间或规模的趋势 | 每方法独特颜色+线型+标记组合（如实线-圆、虚线-方、点线-三角）；黑白可读 |
| 热力图 | 相关矩阵、注意力可视化、方法×benchmark 矩阵 | 连续色标如 Viridis 或 Blue-White-Red；每格标数值 |
| 散点图 | 效率 vs 效果权衡 | X 轴效率指标，Y 轴效果指标；每点标注方法名；Ours 在右上角（如权衡有利于本文） |
| 箱线图 | 多次运行的分布 | 比仅报均值更诚实；显示方差 |
| 雷达图 | 多维能力比较 | 同时跨多个能力轴比较方法时有用 |

如无匹配的，退一步问实验设计是否合理；不匹配任何图表类型的故事通常没有清晰结论。

## 2. 自包含规则

每张实验图必须脱离论文上下文仍可读。这意味着：

- 每个轴有含单位的标签。
- 图例命名每个出现的系列。
- 标题首句陈述图的主要发现，不只是设置。示例："Figure 5: Performance comparison on BIRD benchmark. Our method consistently outperforms all baselines across model sizes."
- 图内使用的缩写在标题或行内定义。

## 3. 科学编码规则

避免图表噪音。不使用：

- 3D 柱状图。
- 背景渐变。
- 装饰性交叉线。
- 多个重叠图例项。
- 夸大小差异的失真纵横比。

使用双重编码。每个系列至少由两个视觉通道区分（颜色和形状，或颜色和线型）。黑白打印的读者应仍能区分曲线。

## 4. 高亮 Ours 规则

如 Ours 占优基线，视觉上区分：

- 深色或饱和色 vs 基线的中性灰。
- 加粗轮廓或标记比基线大。
- 始终出现在一致位置（如柱状图最右列、图例顶部）。

如 Ours 不占优（如 Benchmark 或评估论文的重点是没有方法占优），不要人为高亮一个方法；让读者看到对等。

## 5. 诚实坐标轴规则

- Y 轴起点应诚实选择。如所有方法得分在 60-80%，从 0 开始使差异不可见；从 59 开始夸大。合理起点：55 或 50%，必要时显式标注轴截断。
- 绝不截断 Y 轴顶部而不标明。
- 动态范围跨多个数量级时用对数轴；始终标注为对数。
- 多次运行时应出现误差线或置信区间；在标题中报告方法。

## 6. 画布尺寸与风格一致性

### 画布尺寸

Matplotlib 默认为独立查看设计，非 LaTeX 论文。使用小画布（约 150×100 点），使字体和线在插入栏目时缩放到可读大小。

### 风格一致性

尽早创建 `plot_utils.py` 脚本。定义：

- 色板（如 6 色 ColorBrewer 定性方案，Ours = 索引 0）。
- 线宽（如数据 1.5pt，网格 0.8pt）。
- 字号（如标题 9pt，刻度标签 8pt）。
- 每类图的尺寸。

每张实验图从此脚本导入。结果是论文的视觉一致性，审稿人潜意识将其注册为专业。

## 7. 工具推荐

### 首选：Matplotlib 或 Seaborn

- 代码生成；完全可复现；可版本控制。
- 可从实验输出直接脚本化，无需手动编辑。
- 风格一致地扩展到多图。

### 次选：TikZ 或 PGFPlots

- LaTeX 集成；完全匹配论文排版。
- 初始成本高但视觉集成最干净。
- 期望 LaTeX 原生图的期刊偏好。

### 避免

- Excel 图表插入为图片。质量差；风格不一致；无法从更新数据重新生成。
- 手工编辑图（在 Illustrator 中打开 Matplotlib 输出编辑）。一次性成功，零可复现；下一轮审稿需要从头重新生成。
